# Security Policy

## Supported versions

The latest revision on the default branch is the supported version until a release policy is published.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue or pull request.

Use GitHub private vulnerability reporting for tkskto/sdlint when it is available. If private reporting is unavailable, contact the maintainer privately through GitHub before public disclosure.

Include the affected revision, reproduction steps, impact assessment, and any proposed mitigation in the report.
